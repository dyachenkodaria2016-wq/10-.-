# Цифрова репутація, цифровий слід та принципи цифрового громадянства (10 клас)

Інтерактивний навчальний вебзастосунок (SPA) з інформатики для учнів 10 класу.

## Структура проєкту
```
digital-citizenship-course/
│
├── index.html
├── README.md
├── .nojekyll
│
├── css/
│   └── style.css
│
├── js/
│   ├── app.js
│   ├── content.js
│   ├── simulations.js
│   ├── assessment.js
│   └── report.js
│
└── images/
    ├── digital-footprint.svg
    ├── digital-reputation.svg
    ├── privacy.svg
    └── digital-citizenship.svg
```

## Як запустити локально
1. Розпакуйте ZIP-архів.
2. Відкрийте файл `index.html` у будь-якому сучасному браузері.

## Як завантажити на GitHub та активувати GitHub Pages
1. Створіть новий публічний репозиторій на GitHub (наприклад, `digital-citizenship-course`).
2. Завантажте вміст розпакованого архіву (всі файли та папки повинні бути на найвищому рівні репозиторію, обов'язково файл `index.html` у корені).
3. Перейдіть у розділ **Settings** репозиторію -> **Pages**.
4. У розділі **Build and deployment** у полі **Branch** оберіть `main` та `/ (root)`, після чого натисніть **Save**.
5. За кілька хвилин GitHub опублікує сайт, і ви отримаєте посилання на нього.
